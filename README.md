# Python — Algoritmos e Lógica de Programação 🐍

Repositório criado para registrar minha evolução em **Python**, **Lógica de Programação** e **Algoritmos e Estrutura de Dados** durante o curso de Sistemas de Informação.

O objetivo é acompanhar meu aprendizado de forma prática, organizando exercícios por assunto e registrando minha evolução desde os fundamentos da linguagem até a resolução de problemas com estruturas condicionais e de repetição.

---

## 🎯 Objetivo

Fortalecer minha base em programação e desenvolver principalmente:

- Lógica de programação
- Resolução de problemas
- Construção de algoritmos
- Leitura e interpretação de código
- Capacidade de transformar problemas em soluções
- Prática de programação sem depender apenas de código pronto

Esses estudos também complementam minha evolução em **Desenvolvimento Full Stack**.
